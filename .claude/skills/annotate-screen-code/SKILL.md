# annotate-screen-code

화면 코드에 기획자가 읽을 수 있는 한국어 주석을 추가한다. 주석만 추가하고 코드 동작은 바꾸지 않는다.

## 대상
- 사용자가 지정한 화면 코드 파일(`$ARGUMENTS`).
- 지정이 없으면 어느 파일에 주석을 달지 사용자에게 물어본다. 임의로 고르지 않는다.

## 참고 문서
프로젝트 루트 기준이다. 주석을 달기 전에 먼저 읽는다.
- `PRD.md`: 유저 스토리, 기능 요구사항(F1~F12), 비즈니스 규칙, 열린 질문
- `doc/screens.md`: 화면 목적, 라우트, 구성 요소, 상태, 이동
- `doc/Design.md`: 컴포넌트·토큰 이름

문서가 없거나 읽지 못하면 추측하지 말고 멈추고 사용자에게 알린다.

## 작업 순서

1. **읽기**
   - 참고 문서 3개와 대상 코드 파일을 읽는다.
   - 주석을 달기 전에 대상 파일의 원본을 임시 폴더(scratchpad)에 복사해 둔다. 나중에 코드 동작이 그대로인지 비교하는 데 쓴다.
2. **매핑**
   - 코드의 각 화면·섹션·핵심 동작을 문서의 화면, 구성 요소, 기능 ID(F1~F12), 유저 스토리 번호와 연결한다.
   - 문서에서 근거를 찾을 수 없는 부분은 따로 표시해 둔다.
3. **주석 작성**
   - 코드 파일에 주석을 직접 추가한다.

## 주석 수준
줄마다 달지 않는다. 아래 단위로 단다.
- **화면(파일 상단):** 화면 이름, 목적, 라우트, 해결하는 유저 스토리 번호, 어디서 들어와 어디로 나가는지.
- **섹션:** 화면의 영역(예: 목록 안내, 요금제 카드, 하단 액션)이 무엇을 보여주는지.
- **핵심 동작:** 버튼, 조건 분기, 이동, 저장 같은 동작이 고객에게 무슨 의미인지. 기능 ID가 있으면 함께 적는다.

주석 문법은 파일 형식을 따른다(JSX 안은 `{/* ... */}`, 그 외 `//` 또는 `/* ... */`).

## 주석 형식 예시
```tsx
/**
 * 화면: 요금제 상세 (/plans/:planId)
 * 목적: 선택한 요금제의 월 요금 절감액과 위약금을 나란히 보여주고, 변경 신청을 유도한다.
 * 유저 스토리: 2, 4, 5
 * 이동: 요금제 목록에서 들어오고, 구독 신청으로 나간다.
 */

{/* 절감액과 위약금 (F3, F4): 두 금액만 나란히 보여준다. 위약금 회수 기간 같은 해석은 보여주지 않는다. */}

{/* 변경 신청 버튼 (F5): 고객을 가장 먼저 유도하는 동작. 누르면 구독 신청 화면으로 이동한다. */}
```

## 꼭 지킬 것
1. **코드 동작을 바꾸지 않는다.** 주석만 추가한다. 로직, 변수명, 스타일, 들여쓰기, 줄 순서를 고치지 않는다.
2. **문서에 없는 내용을 지어내지 않는다.** 코드가 하는 일은 설명하되, 그 의도나 정책이 문서에 없으면 추측하지 않고 `[문서에 없음]`으로 표시한다. 예: `{/* 이 버튼의 동작 의도는 [문서에 없음] */}`.
3. **기획자가 이해할 말로 쓴다.** 기술 용어는 풀어 쓰고, PRD.md의 용어(약정, 위약금, 맞는 요금제 등)를 그대로 쓴다. 코드를 그대로 되풀이하는 주석(예: "버튼을 렌더링한다")은 쓰지 않는다.

## 끝났는지 확인
작업이 끝나면 아래 4가지를 모두 확인하고 결과를 사용자에게 보고한다. 확인하지 못한 항목은 못 했다고 그대로 쓴다.

1. **모든 화면·섹션에 주석이 있는가.** 대상 파일의 화면, 섹션, 핵심 동작 중 주석이 빠진 곳이 없는지 확인한다.
2. **코드 동작이 그대로인가.** 작업 전에 복사해 둔 원본과 비교해, 달라진 줄이 주석뿐인지 확인한다. 주석이 아닌 줄이 달라졌으면 되돌린다.
3. **문서 ID가 실제로 있는가.** 주석에 적은 기능 ID(F1~F12)와 유저 스토리 번호가 PRD.md에 실제로 있는지 확인한다.
4. **문서에 없는 내용이 표시되었는가.** 문서에서 근거를 찾지 못한 주석이 `[문서에 없음]`으로 표시되었는지, 근거 없이 단정한 주석이 없는지 확인한다.

## 보고
끝나면 아래를 짧게 알린다.
- 주석을 단 파일과 화면·섹션 수
- 확인 4가지의 결과
- `[문서에 없음]`으로 표시한 곳의 목록 (사용자가 문서를 보완할 수 있도록)
