# screens.md — 화면 설계서

## 요금제 목록

### 목적
요금제별 가격과 제공 혜택을 비교하고, 상세 내용을 확인할 요금제를 선택한다.

### 라우트
/plans
- 제안 라우트. 원본에는 라우트 정의가 없다.

### 구성 요소
- Header (Type=root)
  - 제목: 요금제 목록
- 신규: 목록 안내
  - 나에게 맞는 요금제를 선택하세요
  - 요금제의 상세 내용과 혜택을 확인한 후 구독할 수 있어요.
- Card/Plan (State=default) × 3
  - 베이직: 월 4,900원 / 데이터 3GB · 통화 50분 · 문자 50건
  - 스탠다드: 월 9,900원 / 데이터 10GB · 통화 100분 · 문자 100건
  - 프리미엄: 월 19,900원 / 데이터 30GB · 통화 무제한 · 문자 무제한
  - 각 카드 내부 Button (Type=Secondary, Size=sm, State=Default)
    - 문구: 자세히
    - 동작: 해당 요금제 상세로 이동
- 신규: 설명
  - 모든 요금은 부가세 포함 금액입니다.
- 신규: 하단 안내
  - 요금제를 선택하면 상세 내용을 확인할 수 있어요

### 상태
- 기본: 요금제 카드 3개와 각 카드의 ‘자세히’ 버튼을 표시한다.
- 로딩: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.
- 빈: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.
- 에러: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.

### 이동
- 들어오는 곳:
  - 플로우 시작 지점인 ‘진입’. 이전 화면은 정의되어 있지 않다.
  - 요금제 상세의 뒤로 가기.
- 나가는 곳:
  - ‘자세히’ → 선택한 요금제의 요금제 상세.


## 요금제 상세

### 목적
선택한 요금제의 월 요금, 제공 혜택, 정기 구독 안내를 확인하고 구독 신청으로 이동한다.

### 라우트
/plans/:planId
- 제안 라우트. 원본에는 라우트 정의가 없다.
- planId는 목록에서 선택한 요금제를 구분한다.

### 구성 요소
- Header (Type=default)
  - 제목: 요금제 상세
  - 내부 icon/arrowLeft: 요금제 목록으로 돌아가기
- 신규: 정보 영역
  - 선택한 요금제 이름과 월 요금 표시
  - 화면 예시: 스탠다드 / 월 9,900원
  - 부가세 포함 · 매월 정기 구독
- 신규: 섹션 제목
  - 제공 혜택
  - 구독 안내
- List/Row (Type=default) × 3
  - 화면 예시의 제공 혜택:
    - 데이터: 매월 10GB
    - 통화: 매월 100분
    - 문자: 매월 100건
- 신규: 설명
  - 화면 예시: 신청일부터 이용할 수 있으며, 매월 같은 날짜에 9,900원이 자동 결제됩니다.
- Button (Type=Primary, Size=xl, State=Default)
  - 문구: 구독 신청
  - 동작: 구독 신청으로 이동
- Button (Type=Secondary, Size=xl, State=Default)
  - 문구: 뒤로 · 요금제 목록
  - 동작: 요금제 목록으로 이동

### 상태
- 기본: 목록에서 선택한 요금제의 정보를 표시한다. 선택한 화면은 스탠다드 요금제 예시다.
- 로딩: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.
- 빈: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.
- 에러: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.

### 이동
- 들어오는 곳:
  - 요금제 목록의 ‘자세히’.
  - 구독 신청의 취소.
- 나가는 곳:
  - ‘구독 신청’ → 구독 신청.
  - 헤더의 뒤로 가기 또는 ‘뒤로 · 요금제 목록’ → 요금제 목록.


## 구독 신청

### 목적
선택한 요금제의 신청 내용을 확인하고, 이름과 휴대폰 번호를 입력하여 구독을 신청한다.

### 라우트
/plans/:planId/subscribe
- 제안 라우트. 원본에는 라우트 정의가 없다.

### 구성 요소
- Header (Type=default)
  - 제목: 구독 신청
  - 내부 icon/arrowLeft: 요금제 상세로 돌아가기
- 신규: 섹션 제목
  - 신청 내용
  - 신청자 정보
- List/Row (Type=default) × 3
  - 화면 예시:
    - 요금제: 스탠다드
    - 월 요금: 9,900원 (부가세 포함)
    - 이용 시작일: 2026. 10. 20.
- 신규: 입력 항목 이름
  - 이름
  - 휴대폰 번호
- Input (State=filled) × 2
  - 이름 입력
    - 화면 예시: 홍길동
  - 휴대폰 번호 입력
    - 화면 예시: 010-1234-5678
- 신규: 설명
  - 화면 예시: 신청 내용을 확인해 주세요. 신청일부터 매월 9,900원이 자동 결제되며, 신청 결과는 입력한 번호로 안내됩니다.
- Button (Type=Primary, Size=xl, State=Default)
  - 문구: 신청
  - 동작: 신청 후 신청 완료로 이동
- Button (Type=Secondary, Size=xl, State=Default)
  - 문구: 취소 · 요금제 상세
  - 동작: 요금제 상세로 이동

### 상태
- 기본: 선택한 요금제의 신청 내용과 신청자 입력 항목을 표시한다. 선택한 화면에는 이름과 휴대폰 번호가 입력된 상태로 제시되어 있다.
- 로딩: 미정. 신청 처리 중 표시와 버튼 상태는 정의되어 있지 않다.
- 빈: 미정. 입력 전 화면과 필수 입력 조건은 정의되어 있지 않다.
- 에러: 미정. 입력 검증 조건, 오류 문구, 신청 실패 처리는 정의되어 있지 않다.

### 이동
- 들어오는 곳:
  - 요금제 상세의 ‘구독 신청’.
- 나가는 곳:
  - ‘신청’ → 신청 완료.
  - ‘취소 · 요금제 상세’ → 요금제 상세.
  - 헤더의 뒤로 가기 → 요금제 상세.


## 신청 완료

### 목적
구독 신청 완료 사실과 신청 내역, 다음 결제 정보를 확인한다.

### 라우트
/plans/:planId/subscribe/complete
- 제안 라우트. 원본에는 라우트 정의가 없다.

### 구성 요소
- Header (Type=root)
  - 제목: 신청 완료
- icon/doneMark
  - 내부 icon/check 포함
- 신규: 완료 제목
  - 구독 신청이 완료됐어요
- 신규: 설명
  - 화면 예시: 스탠다드 요금제 신청이 접수되었습니다. 신청 내역을 문자로 보내드릴게요.
- 신규: 섹션 제목
  - 신청 내역
- List/Row (Type=default) × 6
  - 화면 예시:
    - 신청 번호: 20261020-0024
    - 요금제: 스탠다드
    - 월 요금: 9,900원 (부가세 포함)
    - 이용 시작일: 2026. 10. 20.
    - 신청자: 홍길동
    - 휴대폰 번호: 010-1234-5678
- 신규: 설명
  - 화면 예시: 다음 결제일은 2026년 11월 20일입니다. 매월 9,900원이 자동 결제됩니다.
- Button (Type=Primary, Size=xl, State=Default)
  - 문구: 완료
  - 동작: 플로우 종료. 이후 이동 화면은 정의되어 있지 않다.

### 상태
- 기본: 신청 완료 안내와 신청 내역, 다음 결제 정보를 표시한다. 위 번호·날짜·개인정보는 화면에 제시된 예시값이다.
- 로딩: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.
- 빈: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.
- 에러: 미정. 선택한 화면과 플로우에 정의되어 있지 않다.

### 이동
- 들어오는 곳:
  - 구독 신청의 ‘신청’.
- 나가는 곳:
  - ‘완료’ → 플로우의 ‘끝’. 별도의 목적지 화면은 정의되어 있지 않다.
